# 📅 Calendar Scheduler

A simple web-based Calendar Scheduler that allows users to register, log in, and manage appointments. The application includes appointment booking, searching, filtering, dark mode, and reminder features, with data stored using the browser's Local Storage.

## 🚀 Features
- User Login & Signup
- Book Appointments
- Search & Filter Appointments
- Delete Appointments
- Dark Mode
- Real-Time Clock
- Appointment Reminders

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## ▶️ How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.
3. Start scheduling appointments.
